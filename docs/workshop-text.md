## 电网与温控 / Grid & Thermal Console

**标题**

```
电网与温控 | Grid & Thermal Console
```

**简介（工坊简介框，前两行会显示在列表里）**

```
底栏新增「电网」页：一表看全所有电网的发电、耗电、储能与状态；加热器/制冷器可分组，统一设定目标温度，并有季节模式自动断电。
```

**正文**

```
【它解决什么问题】

原版想知道「哪个电网快撑不住了」，只能挨个点电线，点开还只能看那一个网；
十几个加热器制冷器各设各的温度，改一次要挨个点，漏一台就是局部过冷过热。

【功能】

· 电力网络
  全图每张独立电网一行：发电 / 耗电 / 净输出 / 储能（当前·容量）/ 电量% / 状态（正常·放电中·缺电），顶部是汇总。

· 温控分组
  选中加热器或制冷器 → 点 gizmo「温控分组」建组 → 回面板统一调温。
  温度按钮为 [-5][-1] 数值 [+1][+5]。
  同组设备共用设定，解散或移出分组会自动还原各自原来的目标温度。

· 两种模式
  统一：所有设备同一个目标（冷库、单间）。
  季节：热季只开制冷、冷季只开制热，反季那一类【直接断电】——不是把目标设成极端值，待机功耗也省了。
  季节判定用季节平均温度，不是瞬时室外温度，避免一天之内反复切换。

【兼容性】

· 需要 RimWorld 1.7
· 不依赖 Harmony
· 只改原版的「目标温度」和「电源开关」，断电、EMP、故障、过热保护等原版行为全部保留
· 会自动识别所有使用 CompTempControl 的温控建筑（含其它 Mod 的空调/暖气），无需额外兼容补丁
· 对已有存档中的建筑同样生效，无需重建

【已知限制】

· 室温取的是设备所在格的环境温度，嵌在墙里的制冷器可能读到室外侧
· 类型无法识别的第三方温控设备不会被季节模式断电，只跟随目标温度（宁可少控，不猜错方向）

【反馈】

Bug 请附：游戏版本、Mod 列表、Player.log 中搜索 GridThermal 的片段、复现步骤。
GitHub: https://github.com/shuo-liu16/rimworld-mods
```

**标签**：`Mod` `Interface` `QoL`

## 自动清扫 / Auto Clean

**标题**

```
自动清扫 | Auto Clean
```

**简介**

```
每天在设定时刻自动清除居住区污渍：不需要小人动手，不消耗资源，分批处理不卡顿。时刻、范围、提示均可在 Mod 设置调整。
```

**正文**

```
【它解决什么问题】

基地一忙起来就满地血和泥，扫地工永远不够，不扫又掉心情。
这个 Mod 每天到点自动清一次，你不用再管。

【功能】

· 每天固定时刻（默认 06:00）清除居住区内的污渍：血迹、泥、动物粪、碎石堆
· 不需要小人跑过去，也不消耗资源
· 可只清居住区，也可清全图
· 可选是否弹提示
· 设置页有「立即清扫一次」，用于验证是否生效

【性能】

· 主循环里每 256 tick 才检查一次，其余时间只有一次位运算
· 清扫分批进行（每批 300 处），大扫除后不会因为同一帧删掉上千实体而卡顿
· 稳态开销约为每秒 4 次温度·时间判断，对帧率的影响低于测量噪声

【兼容性】

· 需要 RimWorld 1.7
· 需要 Harmony（已声明依赖与加载顺序，启用即可）
· 不改任何原版数值，只删除污渍实体

【已知限制】

· 是「魔法清扫」，没有小人动画，也没有工作量消耗
· 只处理「污渍」实体，不处理尚未落地生成的中间状态
· 如果没画居住区，「只清扫居住区」等于一个都不清

【反馈】

Bug 请附：游戏版本、Mod 列表、Player.log 中搜索 AutoClean 的片段、复现步骤。
GitHub: https://github.com/shuo-liu16/rimworld-mods
```

**标签**：`Mod` `QoL`
